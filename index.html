    Realtime object tracker

    Follows people and vehicles across camera streams and keeps each one's identity when they cross paths or leave the frame. A detector finds the objects and a re-identification model matches them between frames.

    Input
    Camera streams, 1080p at 30 fps
    Output
    Boxes with persistent track IDs
    Runs on
    Edge GPU
    • PyTorch
    • ONNX
    • TensorRT
    • C++

    Defect segmentation with few labels

    Marks surface defects on factory images pixel by pixel. A semi-supervised model learns from unlabelled images, and an active labelling loop asks a person to label only the images it is least sure about.

    Input
    Product images, mostly unlabelled
    Output
    Pixel masks of surface defects
    Training
    Semi-supervised, with active labelling
    • PyTorch
    • Albumentations
    • MLflow

    Depth from a single camera

    Estimates how far away everything is from one ordinary camera, then builds a 3D point cloud a robot can plan a path through.

    Input
    One RGB camera
    Output
    Depth map and 3D point cloud
    Used for
    Robot navigation
    • PyTorch
    • Open3D
    • ROS 2
